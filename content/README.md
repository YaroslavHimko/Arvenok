# Authoring content

- `art-source`: original 2D/3D, rig, animation and audio work.
- `narrative`: story canon, characters, quests and dialogue designs.
- `localization`: translation catalogs and terminology when implemented.

This directory is outside Godot's import root. Export reviewed resources into the game project. See the [content workflow](../docs/contributing/content.md); do not put source assets under runtime paths merely to make them visible to the editor.
