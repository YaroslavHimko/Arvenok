# Art source

Organize as `<discipline>/<collection>/<asset-id>/`, where discipline is `2d`, `3d`, `animation` or `audio`. A collection owns its manifests and export recipes. Copy `asset.example.json` into an asset's folder as `asset.json` and replace every example value.

Binary authoring files use Git LFS; acquire locks when supported. No art is provided by this scaffold. The manifest example is documentation and is not loaded by the game.
