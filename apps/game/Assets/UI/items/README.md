# Inventory placeholder icons

Ten small SVG icons were authored directly for this prototype: sword, shield, log, stone, ore, ingot, pelt, blade fragment, tonic and scroll. They use a 32×32 coordinate grid, transparent backgrounds and crisp-edge geometry. They are placeholders, not part of the supplied Woodvale packs.

The item catalog's `icon` key resolves to the corresponding SVG here. Inventory Controls sample with nearest filtering. Replace these with final art and update the resource binding if the extension/layout changes; keep item IDs and owned inventory data unchanged. No inventory rules or quantities are encoded in icons.
